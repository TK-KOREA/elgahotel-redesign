# 엘가호텔 홈페이지 리뉴얼 시안

[elgahotel.co.kr](https://www.elgahotel.co.kr/) 전면 개편을 위한 디자인 진단과 시안입니다.

| 파일 | 내용 |
|---|---|
| `elga-proposal.html` | 현재 사이트 디자인 진단 + 레퍼런스 기반 5가지 방향 시안(A~E) + 비교·추천 |
| `elga-home.html` | 추천 조합(B 비즈니스 베이스 + A 블랙·골드 톤 + E 모바일 하단 예약바)으로 만든 인터랙티브 시안. `#home` `#rooms` `#location` 3개 화면 |
| `img/` | 현재 홈페이지에서 가져온 로비·복도·객실 사진 11장 |

## 보는 방법

브라우저에서 HTML 파일을 바로 열면 됩니다. 별도 빌드는 없고, 글꼴은 Google Fonts에서 불러옵니다.

## 데이터 기준

- 객실 사진, 객실 구성, 1박 최저가: 2026-11-08 기준 현재 홈페이지와 객실 페이지의 예약 위젯(Wix Hotels) 표기
- 업무지·온천까지 소요 시간, 연박·기업 코드 할인, 주말 패키지: 레이아웃용 **예시**이며 확정 필요
- 조식 뷔페·온천 사진은 원본이 없어 CSS 자리표시로 둠
- 사진 원본이 대부분 가로 1024px라 실제 개편 시 재촬영 권장
